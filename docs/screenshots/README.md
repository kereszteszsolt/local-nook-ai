# Product screenshot gallery

These images are generated by the repository-local deterministic Playwright workflow. They contain only fixed, privacy-safe fixture content and never require a live Ollama model or an existing browser profile.

| View | Stable file | Exact dimensions |
|---|---|---:|
| Desktop conversation | [`desktop-chat.png`](desktop-chat.png) | 1440 × 900 |
| Model selection | [`model-selection.png`](model-selection.png) | 1440 × 1024 |
| System prompt management | [`system-prompts.png`](system-prompts.png) | 1440 × 1024 |
| Rich response rendering | [`rich-response.png`](rich-response.png) | 1440 × 1200 |
| Mobile conversation | [`mobile-chat.png`](mobile-chat.png) | 390 × 844 |

## Gallery contract

- Regenerate all five files together with `npm run screenshots`; do not hand-edit PNG output.
- Keep the filenames and dimensions stable unless a release story explicitly changes the gallery contract.
- Use only the controlled fixtures under `e2e/screenshots/`; never capture a personal browser profile, live conversation, or live model response.
- Review every image at full size after regeneration for private data, fallback alerts, clipped controls, missing fonts, and unreadable rendered content.
- Confirm two consecutive runs have identical SHA-256 hashes before approving changed images.

Detailed prerequisites, the pinned Docker fallback, network boundary, and hash commands are documented in [`docs/testing.md`](../testing.md#deterministic-product-screenshots).
